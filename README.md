# MyQuest 🎮

MyQuest is an interactive, Cyberpunk-themed web platform that allows users to discover, generate, connect, and review real-life "sidequests". The project features a neon-infused aesthetic with a glassmorphism UI, bringing a gamified experience to everyday activities.

## 🌟 Features

- **Procedural Quest Generation**: Generate endless unique sidequests based on difficulty, participants, and categories.
- **Global Navigation Sidebar**: Easy and smooth navigation between Home, Community, Connections, Leaderboard, Feed, and Profile.
- **Glassmorphism UI**: Beautiful frosted-glass effect styling inherited straight from Figma design specifications.
- **Cyberpunk Theme**: `0B0050` Midnight Blue and `#FFFFFF` core colors highlighted with neon Cyan, Emerald, Pink, and Yellow accents.
- **Real-time Quest Registration**: Users can join quests, await approval, or directly commit, with status seamlessly synced to their profiles.
- **Dynamic Leaderboard**: Metallic podium system to highlight top contributors.
- **Interactive Feed & Reviews**: Users can post reviews, attach media, and earn points for completing their quests.

## 🛠️ Technology Stack

- **HTML5 & CSS3** (Tailwind CSS for utility-class styling)
- **Vanilla JavaScript** (ES6+)
- **Lucide Icons**
- **DeArPix Font** (Vietnamese pixel font for headers)
- **Local Storage** (For client-side data persistence)

## 📂 Project Structure

```
myquest/
├── index.html           # Main application entry point
├── css/                 # Custom styles and Tailwind directives
├── js/                  # Application logic (app.js, profile.js, connection.js...)
└── assets/              # Images, icons, and fonts
```

## 🚀 How to Run

Since this is a client-side application, running it is incredibly simple:
1. Clone or download this repository.
2. Open the folder and double-click `index.html` to open it in your web browser.
3. Enjoy exploring MyQuest!
